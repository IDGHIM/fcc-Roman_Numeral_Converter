## 🎯 Objectif du projet

L'objectif de ce projet est de créer une page **Convertisseur de Chiffres Romains** dans le cadre du programme **JavaScript Algorithms And Data Structures** sur [freeCodeCamp](https://www.freecodecamp.org/).

> 💡 Inspiré par :  
[Démo du Convertisseur de Chiffres Romains](https://roman-numeral-converter.freecodecamp.rocks)  
⚠️ *Ne copiez pas directement le projet de démo.*

---

## 📌 Exigences du projet

- [x] Vous devez avoir un élément `<input>` avec `id="number"`
- [x] Vous devez avoir un élément `<button>` avec `id="convert-btn"`
- [x] Vous devez avoir un élément `<div>`, `<span>`, ou `<p>` avec `id="output"`
- [x] Le champ de saisie doit être validé :
  - Vide ➝ "Veuillez entrer un nombre valide"
  - ≥ 4000 ➝ "Veuillez entrer un nombre inférieur ou égal à 3999"
- [x] L'application doit afficher le résultat correct en chiffres romains
- [x] La conversion doit fonctionner pour des cas simples et complexes (ex : 9 ➝ IX, 3999 ➝ MMMCMXCIX)
- [x] Bloquer les entrées invalides via l'interface utilisateur (ex : signe `-` ou `e`)
- [x] Fonctionne aussi avec l'entrée clavier + la touche "Entrée"

> ⚠️ **Important** : Assurez-vous d'inclure ces lignes dans votre HTML pour lier vos fichiers :  
> `<link rel="stylesheet" href="style.css">`  
> `<script src="script.js"></script>`

---

## ✅ Tests du projet (User Stories)

1. `#number` existe en tant qu'élément `<input>`
2. `#convert-btn` existe en tant qu'élément `<button>`
3. `#output` existe en tant qu'élément `<p>`, `<div>`, ou `<span>`
4. Un message d'alerte apparaît si le champ de saisie est vide
5. Une entrée ≥ 4000 affiche "Veuillez entrer un nombre inférieur ou égal à 3999"
6. L'entrée 9 retourne "IX"
7. L'entrée 16 retourne "XVI"
8. L'entrée 649 retourne "DCXLIX"
9. L'entrée 1023 retourne "MXXIII"
10. L'entrée 3999 retourne "MMMCMXCIX"
11. Les entrées de nombres négatifs sont bloquées et affichent le bon message
12. Les grands nombres (≥ 4000) sont bloqués et affichent le bon message
